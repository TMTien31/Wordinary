# Your Isle Assets

Selected isometric PNG renders from Kenney Nature Kit.

- Source: https://kenney.nl/assets/nature-kit
- Author: Kenney
- License: Creative Commons CC0
- Downloaded: 2026-08-18

The pack also includes GLB/OBJ 3D models; this app currently uses the isometric PNG renders for fast, stable browser loading. Credit is optional under CC0, but provenance is kept here so the source remains clear.

`isle-nature-base.png` is a cropped, watermark-free section of the Kenney Nature Kit sample image.

`cozy-wildlife.png` is an AI-generated transparent 3D-style bitmap created for this project to add gentle animal life to the isle.
